# Америкэн бой — Сан-Франциско на 2–4 игрока

Тестовая сборка мультиплеера: одно поле, ходы по очереди, рента и перекуп чужих точек,
побеждает сильнейший по капиталу или первый, кто возьмёт обе лицензии и 3 точки техники.

**Играть:** https://sudarikovandrey.github.io/american-boy-mp/mp.html

Хозяин открывает ссылку, жмёт «Открыть стол» и делится QR или ссылкой — остальные садятся
за стол с телефонов. Связь между устройствами — WebRTC (PeerJS), сервера нет: стол живёт
в браузере хозяина, ему нельзя закрывать вкладку.
